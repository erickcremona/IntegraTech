# .NET MAUI

Siga controles, layout adaptativo, ciclo de vida e versões compatíveis com os SOs de destino. Semântica e leitores de tela variam entre plataformas; valide SemanticProperties e foco em cada SO representativo. Não transportar ARIA, métricas de browser ou regras CSS para controles nativos.

Teste tamanhos/orientações, entrada por toque/teclado, escala de fontes, permissões, offline e retomada conforme o contexto. Browser não comprova UI nativa; runtimes, emuladores/dispositivos e ferramentas apropriadas precisam estar disponíveis e autorizados.

Orientação disponível, gerador MAUI e executor nativo indisponíveis neste incremento. Referência: https://learn.microsoft.com/dotnet/maui/fundamentals/accessibility .
