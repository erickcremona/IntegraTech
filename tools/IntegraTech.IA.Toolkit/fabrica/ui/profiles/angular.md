# Angular

Use componentes, injeção e reatividade conforme a versão aprovada. Material/CDK é opção contextual, não dependência universal; preserve HTML nativo sempre que possível. Componentes acessíveis exigem foco/teclado/nome/estado corretos também na integração da aplicação.

Defina renderização e carregamento por rota; avalie defer com estados acessíveis. Teste forms, navegação, foco após troca de página, mudanças de dados e falhas. Evite aplicar receitas de outra versão de Angular sem conferir compatibilidade.

Orientação disponível, gerador Angular indisponível. Referência: https://angular.dev/best-practices/a11y .
