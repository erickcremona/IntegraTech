# Blazor

Declare explicitamente SSR estático, Interactive Server, WebAssembly ou Auto segundo latência, conectividade, capacidade do cliente e versão do runtime. UI interativa exige serviços e render mode coerentes; prerender pode alterar o ciclo de vida. Não supor interatividade de um componente estático.

Gerencie estado, renderização e JS interop com responsabilidades claras. Teste prerender/hidratação quando aplicável, reconexão nas modalidades server, validação de forms, navegação/foco e custo de inicialização WebAssembly. Avalie biblioteca de componentes compatível sem impô-la.

Orientação disponível, gerador Blazor indisponível neste incremento. Uma API ASP.NET não equivale a frontend Blazor. Referência: https://learn.microsoft.com/aspnet/core/blazor/components/render-modes .
